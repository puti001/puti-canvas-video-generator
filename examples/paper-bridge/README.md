# Puti-AI 紙橋工程師挑戰｜極致進化版 (Pro Evolution)

原創繁體中文國小科學與結構力學教學動畫，1920×1080 30fps Full HD，總長 2 分 15 秒（135.4 秒）。

## 🛠️ 技術與架構升級 (超越 Codex)

1. **極致動態力學向量渲染 (Dynamic Physics Vector Flow)**：
   - **3D 透視擬真書本橋墩**：具備書脊燙金線、真實紙頁層次與動態陰影。
   - **平滑立體摺紙與受力形變**：
     - 平面橋：動態二次方拋物線下垂，紅色集中應力警報區。
     - 折邊橋：兩側直立側壁（Side Beams）支撐分析。
     - 波浪手風琴橋：三角桁架（Truss）動態力量傳導光波，重力箭頭沿著斜坡均勻分散至兩側橋墩。
2. **微觀截面掃描 HUD (Cross-Section Microscope)**：
   - 深入剖析結構抗彎剛度核心秘密：$h \approx 0.1\text{mm}$（平紙） vs $h = 15\text{mm}$（折邊） vs $h = 25\text{mm}$（波浪）。
   - 帶出國小生能懂的幾何物理概念：抗彎剛度與高度成正比。
3. **科學探究與課堂實作教學架構**：
   - 包含：挑戰破題 ➜ 3D 結構展示 ➜ 預測猜想（按暫停討論） ➜ 力學高度秘密 ➜ 三角桁架分散力學 ➜ 公平測試三大約定 ➜ 留白實驗數據表 ➜ 跨距加倍進階挑戰。
4. **全螢幕原生物理彩帶系統 (Native Physics Confetti)**：
   - 結尾動態噴發 90+ 顆具備重力、阻力與三維旋轉的繽紛彩帶。
5. **音訊與配音**：
   - 微軟台灣神經語音（曉臻 `zh-TW-HsiaoChenNeural`）。
   - 自編五聲音階溫暖原聲 BGM ＋ 側鏈自動降音（Ducking） ＋ 動態落幣金屬聲與力學提示音。
   - 獨立 SRT 字幕檔案：`紙橋工程師_極致進化版.srt`。
